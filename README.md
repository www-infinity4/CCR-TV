# CCR TV

CCR TV is a synchronized Creedence Clearwater Revival–led music channel built on the same Infinity live-channel scaffold as the other stations.

## Programming

Creedence leads a rotation of roots rock, swamp rock, blues rock, Southern rock, classic road music, concert footage, and compatible later artists. The starter catalog contains 50 playable music videos and is designed to grow toward the repository brief’s larger archive of concerts, interviews, backstage material, and related programming.

## Broadcast system

- 10-minute fixed station slots; 144 slots per local day and 1,008 per week.
- Videos play to their natural end, followed by a clearly marked intermission until the next slot.
- The deterministic weekly seed changes every Sunday, and the scheduler exhausts the pool before repeating when possible.
- Every viewer joining live sees the same scheduled item and station offset.
- Restart, rewind, Join Live, share/StarCoin, guide, and Picture-in-Picture hooks use the shared channel scaffold.
- Control Phi is the canonical hamburger/remote source; the TNT loader remains as a compatibility fallback.
